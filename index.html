FAQ

Quick answers

Is Sniper Bot free?

Yes, all current features are free to use.

Which permissions does it need?

Administrator is simplest. At minimum it needs to manage channels, send messages and view audit logs for anti-nuke.

How do I trust my admins in anti-nuke?

Run /whitelist and pick the user. Server owners are always trusted.

Who can post payment proofs?

Only members with the Manage Messages permission.
